# 아이랑 나가요

아이별로 외출 준비물을 저장하는 설치형 웹앱(PWA)입니다. 프레임워크나 빌드 단계 없이 Vercel에서 정적 배포합니다.

## v2 기능
- 첫 실행 시 아이 이름, 생년월일, 성별과 생활 정보를 등록합니다. 여러 아이를 따로 관리하며 개월 수는 기기 날짜로 계산합니다.
- 기본 목적지 6개에서 바로 체크리스트를 만들고, 동네빵집·동네도서관 같은 내 장소로 항목과 수량을 저장합니다.
- OpenWeather 현재 날씨를 Vercel 서버 함수로 조회합니다. `OPENWEATHER_API_KEY`는 Vercel 환경변수에만 저장합니다. 지역을 저장하면 앱 실행 시 자동 조회하며 위치 조회와 수동 선택도 지원합니다. AI API는 사용하지 않습니다.
- 체크 진행은 자동 저장됩니다. 저장한 장소에서 새 외출을 시작하면 체크는 초기화되고 선택한 날씨의 추가 항목이 반영됩니다.
- 아이 생활 정보 변경은 새로 시작하는 목록에 반영합니다. 기저귀 사용 여부를 나이로 추정하지 않습니다.
- 이전 버전의 템플릿과 초안은 첫 아이 등록 시 가져옵니다. 이전 저장 키를 삭제하지 않습니다.
- 공유 링크는 준비물 이름과 수량만 포함합니다. 아이 이름과 생년월일은 공유하지 않습니다.
- v2.2: 홈에서 기본 목적지와 내 장소를 먼저 보여주고 날씨 설정은 한 줄로 접어둡니다. 기본 목적지의 이름·항목·수량은 아이별로 수정하고 저장할 수 있습니다.
- 이미지 공유는 기기 안에서 PNG를 생성합니다. 장소 이름, 준비물, 수량, 체크 상태, 생성 날짜가 포함됩니다. 이미지 미리보기에서 기기 공유창 또는 이미지 저장을 사용할 수 있습니다. 긴 목록은 여러 장으로 나눕니다. 이미지와 아이 정보를 서버로 업로드하지 않습니다.

## 저장
`localStorage`의 `aigo_family_v2`에 아이 정보, 아이별 장소, 현재 체크리스트를 저장합니다. 같은 주소에 접속해도 기기와 브라우저별 저장 공간은 독립적입니다. 로그인, 서버 저장, 가족 간 자동 동기화는 없습니다. 사이트 데이터 삭제 또는 기기 변경 시 복원되지 않습니다.

## 실행 및 배포
`python -m http.server 8000`으로 로컬 실행할 수 있습니다. Vercel은 Framework Preset을 Other로 설정하고 빌드 명령 없이 저장소 루트를 배포합니다. 운영 브랜치는 `claude/aigo-pwa-deployment-guide-rrbal9`입니다. 실제 Vercel Production Branch도 일치해야 합니다.

서비스워커는 네트워크를 우선 사용하고 오프라인이면 캐시로 응답합니다. 앱 배포 시 `sw.js`의 캐시 버전도 갱신하세요. 기존 v1 캐시로 실행 중인 앱은 다시 열 때 새 서비스워커 설치 후 자동 새로고침됩니다.

출발 예약 알림 UI는 제거했습니다. 이전 구현의 브라우저 타이머는 앱을 닫은 상태에서 예약 알림을 보장하지 못했습니다.
